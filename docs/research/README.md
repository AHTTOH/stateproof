## 랜딩에 그대로 써도 되는 문장 (출처 각주 포함)

1. "개인정보 보호법은 목적에 필요한 **최소한의 개인정보**만 수집하도록 정하고 있습니다." — 개인정보 보호법 제3조①, 제16조①
2. "근로기준법은 경력(사용)증명서에 **근로자가 요구한 사항만** 적도록 정하고 있습니다." — 근로기준법 제39조②
3. "상시 30명 이상 사업장은 채용 때 직무와 무관한 혼인 여부·재산·가족의 학력과 직업 등을 요구할 수 없습니다(위반 시 과태료 최대 500만 원)." — 채용절차법 제3조·제4조의3·제17조
4. "근로소득 원천징수영수증 서식에는 연봉 외에도 부양가족의 주민등록번호, 의료비·기부금 공제 칸이 함께 들어 있습니다." — 소득세법 시행규칙 별지 제24호서식(1)
5. "JobProof는 원본 대신 '연봉 X 이상', '경력 N개월 이상', '만 18세 이상' 같은 **조건 충족 여부만** 채용 담당자에게 보여 줍니다." — 제품 기능 설명(법적 근거 아님; 실제 구현 상태를 따로 확인한 뒤 사용)
6. "미국 캘리포니아 등 여러 주는 채용 시 이전 연봉을 묻는 것 자체를 금지합니다." — CA Labor Code §432.3, HR Dive 집계
7. "Midnight 테스트넷(Preprod) 위에서 동작합니다." — **실제 Preprod 배포 증거가 있을 때만** 사용
