## 콘셉트

모든 화면이 세로 **봉인선** 하나를 중심으로 짜인다. 왼쪽은 "이 브라우저"(짙은 남색 면, 값이 봉인됨),
오른쪽은 "검증자와 공개 원장"(흰 면, 코발트). 증명이 봉인선을 넘기는 것은 조건 충족 여부와 요청한 값 하나뿐이다.

| 가져온 곳 | 요소 |
|---|---|
| D | 홀더 화면의 항목별 한 줄: 이 브라우저 값, 봉인선, 검증자가 아는 것 |
| E | 코발트 한 색 = 공개 원장에 기록되는 값. 넘어가지 않는 값은 빗금 |
| F | 큰 숫자 위계: 증명 중 경과 초, 영수증의 "검증 완료" |
| G | 증명 상태를 어두운 띠 하나로 |
| H | "이 브라우저" 쪽을 짙은 면으로 |

## 2 pass 에서 바꾼 것

- 첫 화면 슬로건 "조건은 증명하고, 데이터는 지킨다" 제거. 한 줄 설명을 제목으로 쓴다(README 에는 유지).
- 남색 면을 페이지 바탕으로 쓰지 않는다(니어블랙 + 단일 액센트 클러스터 회피). 봉인된 값이 있는 칸에만 쓴다.
- 모든 요소에 같은 둥근 모서리 금지: 봉인선 표는 직각, 버튼만 6px, 증명 띠만 10px.
- 고정폭 서체는 16진수 id 에만. 대문자 라벨, 버튼 끝 화살표 없음.
